# Fork-code/ha-beenthere

Local fork of [tampie85/ha-beenthere](https://github.com/tampie85/ha-beenthere).

Change: any signed-in Home Assistant user can mark and unmark visits
(`toggle_country`, `set_visit`). Managing travellers, groups and map
settings stays admin-only.

Updating: `git fetch upstream && git merge upstream/main`, then push.
